## 📋 ภาพรวมโปรเจกต์

**Anime Fighting Star** เป็นเกมต่อสู้ที่นำระบบสะสมตัวละครมารวมกับการจัดทีมและการผ่านด่าน ผู้เล่นใช้เงินภายในเกมเพื่อสุ่มตัวละครที่มีระดับความหายากแตกต่างกัน เลือกตัวละครเข้าทีม อัปเกรดความสามารถ และนำทีมเข้าสู่การต่อสู้กับศัตรูและบอสในแต่ละพื้นที่

โปรเจกต์นี้ครอบคลุมงานออกแบบเกม การสร้างโมเดล 3 มิติ การออกแบบ UI การสร้างแอนิเมชัน และการประกอบระบบภายใน Roblox Studio โดยเขียนและปรับปรุงสคริปต์ Luau ผ่าน Visual Studio Code

## ✨ ระบบสำคัญภายในเกม

- **Character Gacha** — สุ่มตัวละครจากหลายระดับความหายาก พร้อมระบบ Pity
- **Team Management** — เลือกตัวละครเข้าทีม จัดทีมอัตโนมัติ ล็อก และขายตัวละคร
- **Character Progression** — อัปเกรดเลเวลและรวมตัวละครซ้ำเพื่อเพิ่มความสามารถ
- **Stage & Boss Battles** — ต่อสู้ผ่านพื้นที่ต่าง ๆ พร้อมศัตรูและบอสหลายระดับ
- **Combat & Ultimate Skills** — ตัวละครติดตามผู้เล่น ช่วยโจมตี และใช้ท่า Ultimate พร้อมเอฟเฟกต์
- **Player Progression** — ระบบ Level, EXP, Rank และรางวัลจากการต่อสู้
- **Inventory & Item Pickup** — กระเป๋าเก็บไอเทมและระบบเก็บไอเทมภายในแผนที่
- **Player Data** — บันทึกตัวละคร เงิน เลเวล ทีมที่เลือก และการตั้งค่าของผู้เล่น
- **Movement & Settings** — Dash, Double Jump และเมนูปรับเสียง กล้อง และเอฟเฟกต์

## 📋 ภาพรวม Anime Random Squad

**Anime Random Squad** เป็นเกมแนวสุ่มสะสมตัวละครและจัดทีม ผู้เล่นสุ่มหาตัวละครจากหลายระดับความหายาก เลือกสมาชิกมาสร้างทีม และเพิ่มค่าพลังสะสมของทีมเพื่อนำไปจัดอันดับเปรียบเทียบกับผู้เล่นอื่น ภายในเกมยังมีโหมด PvP สำหรับนำทีมเข้าสู่การต่อสู้ ระบบตัวละครแบ่งเป็นหลายกลุ่ม เช่น Jujutsu Kaisen, Dragon Ball Z และ One Piece

จากโครงสร้างโปรเจกต์ เกมแยกการทำงานระหว่างระบบฝั่งผู้เล่นและเซิร์ฟเวอร์ พร้อมฐานข้อมูลตัวละครและการบันทึกข้อมูลผู้เล่น เพื่อรองรับการจัดทีมและความก้าวหน้าของบัญชี

## ✨ ระบบสำคัญของ Anime Random Squad

- **Character Gacha & Collection** — สุ่มและรวบรวมตัวละครหลายระดับความหายาก ตั้งแต่ Common จนถึงระดับพิเศษ
- **Squad & Team Management** — จัดทีม บันทึกทีม สลับลำดับ และเลือกทีมที่เหมาะกับการต่อสู้
- **Team Power Ranking** — คำนวณค่าพลังสะสมของทีมและนำไปจัดอันดับเปรียบเทียบกับผู้เล่นอื่น
- **Follower System** — แสดงตัวละครในทีมติดตามผู้เล่นภายในเกม
- **Battle & PvP** — ส่งคำท้า ตอบรับคำท้า เริ่มการต่อสู้ และสรุปผลการแข่งขัน
- **Quest System** — ทำภารกิจและรับรางวัลตามเงื่อนไขภายในเกม
- **Daily Rewards** — รับรางวัลประจำวันและติดตามเวลารับรางวัลครั้งถัดไป
- **Codes & Rewards** — แลกรหัสเพื่อรับรางวัลภายในเกม
- **Profile & Leaderboard** — แสดงข้อมูลผู้เล่น สถิติ ทีมที่ดีที่สุด และอันดับผู้เล่น
- **Shop & Game Passes** — รองรับร้านค้าและสิทธิประโยชน์เพิ่มเติมภายในเกม
- **Player Data** — บันทึกตัวละคร ทีม เงิน ภารกิจ รางวัล และความก้าวหน้าของผู้เล่นด้วย Roblox DataStore

## 🛠️ โครงสร้างที่ตรวจสอบจากโปรเจกต์

| ส่วนประกอบ | หน้าที่ |
| --- | --- |
| `SquadClient` | จัดการหน้าจอ การจัดทีม โปรไฟล์ ร้านค้า ภารกิจ รางวัล และการแสดงผลการต่อสู้ฝั่งผู้เล่น |
| `SquadServer` | จัดการข้อมูลผู้เล่น ทีม ระบบติดตาม ภารกิจ เงิน รางวัล และการต่อสู้ฝั่งเซิร์ฟเวอร์ |
| `PlayerDatabase` | เก็บข้อมูลตัวละคร ระดับความหายาก ค่าพลัง และชื่อโมเดลที่ใช้ในเกม |
| `CharacterModels` | รวมโมเดลตัวละครที่ใช้สร้างทีมและแสดงภายในเกม |
